SiriusXM Sidecar for macOS

1. Install Python 3.14 from python.org/downloads/macos/.
2. In Terminal, run: python3.14 -m pip install requests
3. Install FFmpeg and make sure `ffmpeg` is available on PATH.
4. Double-click Run Sidecar.command and enter your account details.

The current sxm.py script is included inside the executable. This disk image
is unsigned. macOS may require approval in System Settings > Privacy & Security
before opening the launcher.
